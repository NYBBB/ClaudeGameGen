## 口径

- 有效耗时：从发出提示词到交付汇报的墙钟时间，减去超过 20 分钟的空闲段（等用量重置、报错后无人处理）。期间 Claude 自己截图自检、跑浏览器的时间都算在内。
- Token：每个 API 调用取最终 `usage`，按 `message.id` 去重；`<synthetic>` 消息（用量上限、报错提示）不算。
