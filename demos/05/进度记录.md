**已经定位到的生硬原因**

- 步态（`50-rig.js` 的 `locoPose`）：脚沿余弦轨迹前后摆，支撑期速度不是匀速，所以脚在地上打滑；骨盆只有简单上下起伏；右手不摆臂；没有脚跟着地／脚尖离地；站立时几乎完全静止。
- 速度（`80-combat.js` 的 `Player.update` `free` 分支）：速度直接设成目标值，没有加减速，起步和急停都是瞬间完成；转向没有身体倾斜。
- 镜头（`90-game.js` 的 `updateCamera`）：跟随点用很硬的阻尼贴在玩家身上，没有滞后、前瞻和自动回正；受击只有随机抖动，没有方向性冲击。

**计划（按顺序）**

1. 步态重做：按“支撑相／摆动相”写脚轨迹，支撑期脚相对身体匀速后移（世界坐标里钉住不动），步频随速度变化；加骨盆侧摆、旋转、摆动侧下沉，脊柱反向扭转，双臂摆动，脚掌俯仰（需要给姿势加 `lfp`／`rfp` 两个标量通道），原地转身时小碎步，站立时的重心转移和呼吸。
2. 速度：给玩家加真实的加减速（时间常数约 0.1 秒）、冲刺渐入、急停小滑步、转弯侧倾和加速前倾。
3. 镜头：水平方向弹簧滞后、朝移动方向的前瞻、长时间不动鼠标时缓慢回正、随速度变化的视野、命中时的方向性冲击和视野冲击、轻微手持晃动。
4. 手感：出招时自动贴近目标（按距离伸缩突进量）、突进用缓入缓出曲线。
5. 打击感：顿帧期间受击者原地抖动、血和刀光顺着刀尖速度方向、命中刀光按挥砍方向在屏幕上定向、重击时敌人被打离地、完美弹反后短暂慢放。
6. 建模：四肢改成带肌肉轮廓的旋转体、手脚细化、腰间剑鞘、腰带飘带、石灯笼和倒伏竹子等场景小物。
7. 自检：用脚的世界坐标量化滑步量，记录镜头加速度峰值，重跑自动通关和音频检查，再更新本记录。

## 任务要点（原始需求摘要）

- 写实风格、第三人称东方剑术动作 ARPG，完整的“雨夜竹径”关卡。
- 战斗：快节奏连招、技能、格挡、弹反、闪避、架势、处决；全部动作／命中／受伤都要有视觉和音效反馈。
- 受击硬直短；闪避和格挡能取消玩家自己的攻击；闪避还能在倒地时快速起身。
- 敌人倒地死亡后消散为粒子。
- 美术：冷色调暗黑写实，细雨薄雾、高竹、湿石阶，红灯笼暖光对比；亮度适中不过暗。界面只用英文。
- 单文件 HTML，只能从 CDN 引库，不加载外部模型／图片／音频。输出 `demos/05/index.html`。
- 自检：用 `agent-browser` 截图；声音用 OfflineAudioContext 渲染后查峰值／削波／静音段，汇报里写“未经人耳试听”。
- 最后用 3–6 行汇报：做了什么、文件路径、已知问题。

### 自检结果

- **截图检查**：标题页、开场、三段石阶、四块空地、山门庭院；玩家与四类敌人的造型；连招／受击／倒地／快起／弹反／闪避／喝药等关键帧；处决演出；死亡消散近景；三个剑技；Boss 战实况（带 HUD）；死亡页；通关页。
- **画面亮度**：六个位置的平均亮度 0.25–0.28（0–1），不暗。
- **脚本模拟**：挨打、按住格挡、卡点弹反、闪避、架势崩溃 → 处决、被横扫击倒 → 按闪避快速起身（0.85 秒回到可行动，正常起身 1.8 秒）、死亡 → 重生，状态流转都对。
- **自动通关**：写了个“完美防御”脚本，不开无敌从头打到通关，游戏内耗时约 72 秒，0 次运行时报错。
- **性能**：1280×720、三名敌人围攻时稳定 60 帧（帧时间 16.7 ms，p95 16.8 ms）；每帧约 158 次绘制调用、40 万三角面。
- **真实流程**：全新加载 → 真实点击开始按钮 → 进入游戏、音频上下文启动成功。无头浏览器拿不到鼠标锁定，走的是回退路径。
- **音频（未经人耳试听）**：30 个音效全部有声，峰值 0.04–0.72，削波采样数 0；平静段混音峰值 0.40、RMS 0.066；战斗段混音峰值 0.81、RMS 0.116；两段混音都没有静音段。

### 自检中抓到并修掉的问题

- 未激活的敌人全堆在世界原点 → 生成时先定位再隐藏。
- 布带法线朝向反了，显得发白 → 调整三角面绕序。
- 地面和竹叶在掠射角反光过强，像积雪 → 降低环境反射。
- 角色太像人偶 → 加蓑衣披肩、面巾、长袖、五官，Boss 加厚体型和分层肩甲。
- 带高通滤波的噪声层在起音那一个采样点会漏出满幅脉冲（增益自动化晚一帧生效）→ 增益节点初始值设 0。
- 混响脉冲每次随机生成，持续音响度不稳定 → 改成固定种子。
- Boss 被弹反几次就崩架势 → 降低对 Boss 的弹反架势伤害，提高血量和架势上限。

### 调试接口 `window.__dbg`（自检用，保留在成品里）

- `start()` 不要鼠标锁定直接进游戏；`manual(true)` 停掉自动帧循环；`step(n, dt)` 手动推进。
- `tp(z, u)` 传送；`press('attack'|'dodge'|'guard'|'q'|'e'|'r'|'exec'|'heal')`；`hold('w'|'guard'|'sprint', bool)`。
- `pose(who, clip, t)` 把某个角色定在某个动作的某一时刻（`who` 为 `'p'` 或敌人下标）。
- `look(who, 角度, 距离, 高度, fov)`、`view([...])` 自由镜头；`view(null)` 还原。
- `sheet([fn...], 列数)` 把多帧拼成一张图再截图；`unsheet()` 关掉。
- `info()` 状态快照；`lum()` 画面平均亮度；`drawStats()` 绘制调用数；`G`、`CAM`、`Post`、`FX`、`Input` 是内部对象。
- `window.__audioTest()` 返回每个音效和两段混音的峰值、RMS、削波采样数、静音段；`window.__au` 是音频内部函数。
- 注意：玩家一旦进过 Boss 区（z > 179.8），`bossOn` 会把玩家锁在庭院里，测试别的区域前要重新加载页面。

## 已知问题

- 角色是用基本几何体拼的，属于“风格化写实”，达不到真人模型的写实度；脸部只有简单五官。
- 动作是程序化关键姿势插值，只看过关键帧截图，没有连续观看过，实际流畅度没有肉眼确认。
- 声音只做了电平检查，未经人耳试听，音色和混音好不好听没法保证。
- 难度没有真人试玩过；完美防御脚本 72 秒通关，说明数值偏向“弹反流很强”。
- 鼠标锁定、Esc 暂停这条路径在无头浏览器里测不了，只验证了回退路径。
- 只在 1280×720 测过；高分屏下像素比上限 1.5，掉帧时会自动降分辨率（这条降级逻辑没被触发过）。
- 竹叶是面片，近看有硬边；草编纹理偏规则。
- 没有按 `CLAUDE.md` 在 `games/` 和 `测试记录/` 下建文件，因为任务要求产物只写到 `demos/05/`。
